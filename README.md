# 💻 Projetos em C

> Repositório dedicado aos meus estudos, exercícios e projetos desenvolvidos durante minha jornada de aprendizado da linguagem **C**.

Aqui registro minha evolução na programação em C, desde os primeiros conceitos da linguagem até projetos que exploram estruturas, lógica e recursos mais avançados.

🎯 **Objetivo:** aprender C na prática, escrever código cada vez mais organizado e construir uma base sólida em programação.

---

## 🚀 Sobre o projeto

Este repositório funciona como um **laboratório de estudos**.

Cada projeto representa uma etapa da minha evolução na linguagem, permitindo acompanhar não apenas os resultados, mas também a evolução da minha lógica de programação e da qualidade do código.

📚 Entre os principais conceitos estudados estão:

- 🔹 Sintaxe e estrutura da linguagem C
- 🔹 Variáveis e tipos de dados
- 🔹 Entrada e saída de dados
- 🔹 Operadores e expressões
- 🔹 Estruturas condicionais
- 🔹 Estruturas de repetição
- 🔹 Funções
- 🔹 Arrays e strings
- 🔹 Ponteiros
- 🔹 Structs
- 🔹 Manipulação de arquivos
- 🔹 Alocação dinâmica de memória
- 🔹 Organização e modularização de código
